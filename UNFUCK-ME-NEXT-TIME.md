## The rule under all of it

When you repeat yourself, the delivery format failed — not you. Switch format immediately (chat block → file card → different tool). Never re-litigate that it was "already done."

## Fastest formats, matched to ask

- "give me X" / "prompt pack" → fenced code block in chat, or a written file + presented card. No prose around it.
- "copyable / markdown / one block" → the copyable-markdown skill, one fenced block, copy button.
- "find / recover / scrub" → do it in the sandbox, show only counts and the final artifact.
- shell commands → fenced block, literal paths, zero placeholders, zero bare `$VARS`.
